# Md. Raghibul Islam — Personal Portfolio

## Folder structure

- `index.html` — main portfolio page
- `css/style.css` — styling and responsive design
- `js/script.js` — navigation, animations, project filtering and back-to-top
- `assets/Md_Raghibul_Islam_CV.pdf` — downloadable CV
- `images/hospital-system.jpg` — add your real hospital project screenshot here

## Before publishing

1. Replace `[University Name]`, `[Your Email]`, `[Your Location]`, etc.
2. Replace the example GitHub and LinkedIn URLs.
3. Replace the skills with your actual skills.
4. Add your hospital project screenshot as `images/hospital-system.jpg`.
5. Add your GitHub project URL.
6. Create a Formspree form and replace `YOUR_FORM_ID` in `index.html`.
7. Test the Download CV button.

Open `index.html` in a browser to preview the portfolio.
